# SmartPrint

An Android floor-plan design app built as a semester project and continued independently.

## Features

- Draw walls and place doors and windows
- Select objects, pan, and zoom
- Scale drawings using real-world measurements
- Undo editing actions
- Save floor plans locally and browse saved designs
- Export floor plans to PDF
- Save designs using Firebase
- Calibrate measurements from a camera image using a known reference distance

## Technologies

Kotlin, Jetpack Compose, Firebase, JSON, and Android Studio.

## My Contribution

Developed the Android interface, floor-plan editing tools, measurement features, persistence, and export functionality.

## Getting Started

1. Clone this repository.
2. Open the project in Android Studio.
3. Configure your own Firebase project for this Android app.
4. Place your Firebase `google-services.json` file in the `app/` directory.
5. Allow Gradle to sync, then run the app on an emulator or Android device.

Firebase configuration and machine-specific settings are excluded from this repository.

## Project Status

This project began as coursework and remains under independent development. It is a prototype; measurements should be verified before practical use.
